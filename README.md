## Objective
To create a student profile using variables of different data types in JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript

## Data Types Used
- String: Student name, course and college
- Number: Age, semester and CGPA
- Boolean: Student status
- Array: Skills
- Object: Student location

## Features
- Displays student information
- Uses different JavaScript data types
- Shows a simple, responsive profile card
- Uses JavaScript template literals to display data dynamically

## How to Run
1. Open the HTML file in a web browser.
2. The student profile will appear on the screen.
